# ADR-000: Title in the imperative

**Status:** Proposed | Accepted | Superseded by ADR-XXX
**Date:** YYYY-MM-DD
**Deciders:** who
**Supersedes:** ADR-XXX (if any)

## Context

What forces this decision now? What constraints apply — technical, cost,
operational, legal? What happens if we do nothing? Be concrete; include numbers
where numbers exist.

## Options considered

### Option A — name

How it works, and what adopting it costs.

**For:** ...
**Against:** ...

### Option B — name

...

## Decision

What we chose, stated plainly.

## Consequences

**Positive:** what this buys us.

**Negative:** what this costs us. Be honest — an ADR with no negatives is an
advertisement, not a decision record.

**Neutral:** what changes without being clearly better or worse.

## Reversal conditions

The specific, measurable conditions under which we would revisit this. If you
cannot name them, the decision is not well understood yet.

## Migration path

If reversed, how do we get from here to there, and roughly what does it cost?
